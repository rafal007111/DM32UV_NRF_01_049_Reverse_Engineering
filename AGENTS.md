# Agent instructions

Target only Baofeng DM32UV, firmware DM32.NRF.01.049. Read README.md, docs/RE_NOTES.md and docs/DECOMPILED_MODULES.md before work.

Use static analysis by default. Never open a radio serial port or write the radio from an unattended agent. Hardware tests belong to the owner. A request to analyze code does not imply permission to install firmware.

Decompiler output may have incorrect types, function boundaries or control flow. Preserve autogenerated addresses until evidence supports a semantic name. Mark findings hardware-verified, code-verified, inferred or unreviewed. Record addresses, hashes, tool version, caller/data-flow evidence and user hardware results.

Before proposing a program image, confirm exact baseline hash, guard every patch byte, audit module placement/size and branch targets, preserve boot prefix/startup/heap invariants, and compare the complete image. A successful module build is not a complete firmware image. Preserve CPS/codeplug compatibility and TX/PTT behavior.
